# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to label strings in GitHub Issues.

| Canonical role | GitHub label | Meaning |
|----------------|--------------|---------|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AI agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or review |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use the corresponding label from this table.

## Additional labels (optional)

| Label | When to use |
|-------|-------------|
| `mvp` | In scope for Phase 1 |
| `phase-2` | Deferred |
| `blocked` | Waiting on another issue |
